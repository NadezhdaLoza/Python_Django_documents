# Python_Django_documents

Учебный веб-проект для автоматизации создания и учета документов. Реализован на стеке Python/Django с использованием PostgreSQL.

## Стек технологий

- **Backend:** Python 3.13, Django 5.1
- **Database:** PostgreSQL (psycopg2-binary)
- **Frontend:** HTML/CSS (шаблоны Django), Bootstrap (опционально)
- **IDE:** VS Code

## Архитектура проекта

Проект построен по модульной архитектуре Django. Каждое приложение отвечает за отдельный справочник или документ:

- `accounts`, `customers`, `departments`, `employees`, `organizations`, `positions`, `products`, `units` — справочники системы.
- `proxies` — основной модуль документа «Доверенность».

Используется паттерн CBV (Class-Based Views) для реализации CRUD-операций. Маршрутизация настроена через вложенные `urls.py` с использованием namespaces.

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone [ссылка_на_репозиторий]
   cd crm
   ```
2. Создайте виртуальное окружение и установите зависимости
3. астройте подключение к базе данных в settings.py:
   Укажите параметры DATABASES для вашей локальной PostgreSQL. Не забудьте создать базу данных и пользователя.
4. Примените миграции и создайте суперпользователя
5. Запустите сервер разработки:
   ```bash
   python manage.py runserver
   ```
6. Перейдите в браузер: http://127.0.0.1:8000/proxies/

## Структура данных

Каждый справочник реализует полный цикл CRUD. Модели связаны через внешние ключи (ForeignKey). В административной панели зарегистрированы все модели для управления контентом без написания дополнительного кода.

## Особенности реализации

- Использование SuccessMessageMixin для уведомления пользователей об успешных операциях.
- Обработка ProtectedError при удалении записей, на которые ссылаются другие объекты.
- Кастомизация отображения моделей через методы **str** и класс Meta.
